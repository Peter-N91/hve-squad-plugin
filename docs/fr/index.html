hve-squad-plugin
Plugin Copilot · Distribution générée

La squad, installable sous forme de plugin GitHub Copilot.

Ce dépôt est un miroir généré de l’arborescence de distribution du plugin Copilot CLI de Peter-N91/hve-squad, publié uniquement lors des versions. Une seule installation suffit pour que les agents hve-squad:squad-* soient disponibles dans Copilot CLI, VS Code et l’application de bureau Copilot — sans avoir à exécuter apm install.

Ce que fournit ce dépôt

hve-squad-plugin n’est jamais modifié manuellement. Son contenu est régénéré uniquement lorsque hve-squad publie une version, à partir du tag Git immuable de cette version — jamais à partir d’un arbre de travail actif ou d’une branche évolutive. Il regroupe trois éléments :

🤖

27 agents

Tous les agents Copilot de la squad présents dans agents/squad/ — le coordinateur, le coordinateur de fédération et l’ensemble des spécialistes (implémentation, revue, recherche, analyse critique, tenue des registres, etc.).

🧠

La compétence squad et 7 compétences d’invocation

La compétence qui définit les procédures opérationnelles de base dans skills/squad/, ainsi que invocations/ : squad-run, squad-doctor, squad-document, squad-federation, squad-governance-report, squad-init-hooks et squad-learn.

🛡️

Contrôles via hooks.json

Des scripts de hooks déterministes, appliqués dans la mesure du possible (preToolUse, postToolUse, subagentStop, sessionStart, userPromptSubmitted), qui renforcent le point de contrôle des actions à impact de la squad, la règle d’un rédacteur unique de l’état et les garde-fous de délégation — consultez hooks/README.md pour savoir précisément ce que chacun peut ou ne peut pas faire respecter.

🔌

Configuration via .mcp.json

Enregistre le serveur compagnon @hve-squad/mcp via stdio, afin qu’un hôte en mode délégué puisse appeler la squad sous forme d’outils (squad_research, squad_plan, squad_review, squad_architect, squad_run), en complément de la délégation directe aux agents.
